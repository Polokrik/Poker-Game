# Hold'em Académie

Apprendre le Texas Hold'em : cours en 6 chapitres, quiz, histoires de légendes et simulateur d'équité.
Site statique (HTML/CSS/JS, sans build), compatible mobile et PC. Déployé sur GitHub Pages via `.github/workflows/pages.yml`.

Ouvrir `index.html` en local suffit pour tester. Le détail du projet est dans `poker-app-prompt.md`.

- Mode jeu contre bots (débutant, intermédiaire, avancé)
